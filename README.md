# Paradise View

**Codename:** Paradise View

A hotel booking website prototype designed for a university Human Computer Interaction module. Users can book a room across four UK locations, choose a room type, select dates, and add extras such as breakfast and gym passes.

## Features

- Room search by location, room type and dates
- Add-ons: breakfast and gym passes
- Checkout with a live price breakdown
- Dropdown navigation for locations, rooms and food

## Design

The prototype was designed in Figma and shaped around older luxury-hotel guests, with clear labels and a minimalist look.

Figma prototype: [View the design in Figma](https://www.figma.com/design/kLOXfPfxUP4ptT7GR9oFIT/hotel?node-id=152-451&t=trgckIrhJkf9v1XE-1)

## Testing

The team ran a cognitive walkthrough and three user scenarios, then suggested improvements such as a search bar and a booking summary page.
